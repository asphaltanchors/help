When you remove a seasonal structure or other attached object, install a short set screw in each exposed anchor. The set screw acts as a removable plug that keeps snow, sand, rocks, dirt, ice, and other debris out of the internal threads.

This is useful for carports, canopies, speed bumps, signs, equipment, and anything else that is removed during the off-season or between uses.

## Choose the correct set screw

The set screw must match the anchor's internal thread:

| Anchor | Thread size | Set screw source |
| --- | --- | --- |
| [[SP10]] | 3/8"-16 UNC | [3/8"-16 set screws at McMaster-Carr](https://www.mcmaster.com/products/set-screws/thread-size~3-8-16/) |
| [[SP12]] | 3/8"-16 UNC | [3/8"-16 set screws at McMaster-Carr](https://www.mcmaster.com/products/set-screws/thread-size~3-8-16/) |
| [[SP18]] | 7/16"-14 UNC | [7/16"-14 set screws at McMaster-Carr](https://www.mcmaster.com/products/set-screws/thread-size~7-16-14/) |
| [[SP58]] | 5/8"-11 UNC | [5/8"-11 set screws at McMaster-Carr](https://www.mcmaster.com/products/set-screws/thread-size~5-8-11/) |

Choose a short, headless set screw with an internal hex drive. It should be long enough to engage securely without being difficult to retrieve.

## Install the set screw

1. Remove loose dirt and moisture from the anchor opening.
2. Apply a small amount of anti-seize lubricant to the set screw threads.
3. Thread the set screw into the anchor by hand to avoid cross-threading.
4. Use a hex key to position it flush with or slightly below the anchor head.
5. Tighten it only enough to keep it in place.

:::caution
Never leave the set screw protruding above the anchor. A raised screw can create a trip hazard and may interfere with vehicles, snow removal, or other equipment.
:::

For zinc plated or steel anchors, use Permatex #80078 anti-seize. For stainless steel anchors, use Permatex #77124 anti-seize. Anti-seize is particularly important with stainless steel because dry stainless threads can gall and seize.

## Return the anchor to service

When you are ready to reinstall the structure:

1. Remove the set screw with the correct hex key.
2. Clean out any grit, moisture, or residue around the opening.
3. Inspect the internal threads before installing the mounting bolt.
4. Reapply anti-seize to the mounting bolt if needed.

A set screw protects the threads from ordinary debris, but it should not be treated as a watertight seal.
