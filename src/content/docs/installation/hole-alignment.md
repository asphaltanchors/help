Mark every hole before you drill. The goal is a starter hole at least 1/2" deep at each anchor location. A masonry bit skips and wanders on the asphalt surface before it bites, so a hole that starts on a pen mark can still end up off target. A 1/2" starter hole holds the bit in place, so each hole starts where you marked it.

How you make the starter hole doesn't matter. Use whatever works with the tools you have and the object you are anchoring.

## Why it matters

When you install more than one anchor for the same object, the holes must match the mounting holes in that object. Small errors add up quickly: a hole that is off by 1/4" may still work for two anchors, but with four anchors it can be nearly impossible to get every bolt to line up.

Marking makes even tight patterns work. We have installed SP58 anchors 5" apart, the minimum spacing, and had every bolt line up. See the [spacing requirements](/installation/anchor-install/#anchor-specifications) for how close anchors can go.

## Find the hole locations

Use whichever of these fits the job:

* **Use the object itself.** If you can reach the mounting holes, set the object exactly where it will go and make the starter holes through its mounting holes. This only works if your punch or pilot bit fits through the holes. Many punches and chisels have a thick shank behind the tip that won't fit.
* **Make a template.** Trace the mounting holes from the object, or measure and mark the hole pattern carefully, on paper, cardboard, plywood, or anything else you can mark accurately. Mark the center of each hole and lay the template exactly where the object will go. Use a template when the object's holes are too small for your tool, or can't be reached once the object is in place, such as a bollard with hidden bolts.

## Make the starter holes

Any method that leaves a hole at least 1/2" deep on each mark works. For example:

* **Punch or chisel.** Place the tip of a center punch, pointed chisel, or other sharp steel point on the mark and hammer it 6–10 times, until it is at least 1/2" into the asphalt. Tap it side to side to free it.
* **Pilot hole.** Drill a 1/4" hole at least 1/2" deep on each mark. This is very fast, but needs a second drill and bit so you don't have to swap bits for every hole.

See [Center punches and chisels](/product-info/local-accessory-alternatives/#center-punches-and-chisels-for-marking-holes) for examples you can buy locally.

Then start the full-size bit in each starter hole and continue with the normal [installation steps](/installation/anchor-install/#critical-installation-steps).

:::tip
Make every starter hole before drilling any full-size hole. If you drill one hole at a time and re-measure from it, any error in the first hole carries into the rest.
:::
